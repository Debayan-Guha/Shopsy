# Shopsy

## Java-Based Shopping Application

### Overview
Shopsy is a Java-based shopping application designed to provide a seamless online shopping experience. The application features a user-friendly interface, secure payment processing, and a vast catalog of products.

### Features
- **User Authentication**: Secure sign up and login functionalities.
- **Product Catalog**: Browse products by categories with search functionality.
- **Shopping Cart**: Add, remove and manage products in your cart.
- **Checkout Process**: Secure checkout with various payment methods.
- **Order Tracking**: Users can track their orders in real-time.

### Technologies Used
- **Java**: Backend development using Java SE and Java EE.
- **Spring Boot**: Framework for building RESTful APIs.
- **Hibernate**: ORM framework for database interactions.
- **MySQL**: Database to store user and product information.
- **Thymeleaf**: Template engine for rendering web pages.

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/Debayan-Guha/Shopsy.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Shopsy
   ```
3. Install necessary dependencies:
   ```sh
   mvn install
   ```
4. Run the application:
   ```sh
   mvn spring-boot:run
   ```

### Usage
Once the application is running, you can access it through your web browser at `http://localhost:8080`.
